The Markdown editor that keeps every document self-contained

Inkase is a lightweight Markdown editor and document workspace with three editing modes — WYSIWYG live rendering, source and split view. Its innovative .mdx format packs Markdown content together with images and attachments into a single ZIP file — one file is all it takes to carry your whole document.

The .mdx file format

Every .mdx file is a standard ZIP archive that any unzip tool can open. Simple, transparent, lock-in free — your documents belong to you.

📄 project-plan.mdx
├─ mdx.json # metadata
├─ content.md # Markdown body
└─ assets/
   └─ images/ # embedded images

Share as one file

Project Plan
Write & see

Split preview

Write Markdown on the left, watch it render on the right — synchronized scrolling, with a draggable divider.

More features

A complete toolchain built for the long haul

🖼️

Auto-packed images

Paste or drop an image and it goes inside the document with relative references — no more broken links or missing paths.

🔄

Format interoperability

Import DOCX / Markdown files and whole folders, export Markdown / PDF with batch support.

📁

Folder workspace

Browse, create, rename and drag-move files like a file explorer, with multi-tab editing across documents.

🤖

Built-in AI assistant

Works with any OpenAI-compatible endpoint. Reads, writes and searches documents — every tool call is reviewable and previewable.

🔍

Workspace search

Ripgrep-powered full-text search across files, plus millisecond quick-open (Ctrl+P).

🛟

Autosave & recovery

Editing snapshots are taken in real time and restored after a crash; external file changes are watched and reloaded.

🌓

Light & dark themes

Dark, light or follow-the-system, with restrained consistent colors that stay easy on the eyes.

🔀

Git sync

Attach a Git repository to pull and push documents in one click, with visual conflict resolution.

💻

Cross-platform

Installers for Windows and Linux (NSIS / zip / AppImage / deb); macOS support is on the way.
