.mdx 文件格式

每个 .mdx 文件都是一个标准 ZIP 压缩包——用任何解压工具都能打开。 简单、透明、无锁定，你的文档只属于你。

📄 项目规划.mdx
├─ mdx.json # 文档元数据
├─ content.md # Markdown 正文
└─ assets/
   └─ images/ # 内嵌图片
