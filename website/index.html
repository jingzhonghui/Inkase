#一篇文档，就是一个文件

Inkase 是一款 Markdown 编辑器。它把正文、图片和附件一起打包进单个 .mdx 文件——拷走它，整篇文档就完整地带走了，不会出现「图丢了」。

免费下载 查看源码

##.mdx 是什么

它是标准 ZIP 压缩包，不是私有格式。里面只有三样东西：一份元数据、一份纯文本 Markdown，和一个资源目录。十年后换任何工具，它们依然打得开。

##PDF 与图片

PDF、图片直接在标签页里只读打开，不转换格式、不改动原文件。深色模式下整页反色，夜里翻长文档不刺眼。

产品手册.pdf − 100% + 3 / 24

第三章　部署

把 .mdx 放进工作区目录，Inkase 会在启动时扫描并建立索引，不需要额外的资源服务器。

图片与附件都收在包内，路径相对于 content.md，因此不会有断链的图。

导出 PDF 时走的是与预览一致的渲染管线，字体、代码高亮、数学公式都会保留下来。

反色由 invert(.9) hue-rotate(180deg) 完成——白纸黑字变成深灰底浅字，嵌入图片的色相几乎不动。点右上角试试。

  • ✓

    只读打开，不落地

    PDF 与图片在独立标签页里渲染，不转格式、不写临时文件。关掉标签，原文件一个字节都没变。

  • ✓

    批量导出 PDF

    整个文件夹一次导出，进度逐条可见，中途可以取消。单篇导出和批量导出共用同一套渲染管线。

  • ✓

    图片与附件同处一室

    拖进来就自动收入文档的 assets/，按内容校验和去重；查看器直接读包内资源，不走网络。

##同步v0.3.5 新增 WebDAV

两种后端任选其一：绑一个 Git 仓库，或者连一个 WebDAV 网盘。拉取、推送、冲突处理都在面板里完成，不用碰命令行。

同步
仓库 jingzhonghui/notes 3 分钟前
main 已同步 本地 2 处改动
自动推送
项目规划.mdx 冲突
本地 12 行改动 · 远程 8 行改动 · 两边都动过同一段

.inkase/ 是本机私有配置，会自动写进 .gitignore；如果它已经被跟踪，Inkase 会先把它从索引里摘掉再提交。老版本的 .markdownPlus 目录也会在绑定时自动迁移。

服务地址 https://dav.example.com/remote.php/dav/files/me
用户名 me
口令 ••••••••••
远端目录 /inkase/notes
webdav 已同步 刚刚
自动推送

口令经系统凭据加密后单独存放，绝不写进 .inkase/sync.json。WebDAV 没有「提交」这一层，改动直接推送；每个文件按 ETag 比对，远端被别人改过就报冲突，而不是默默覆盖。启用时不执行任何 git 命令。

  • ✓

    两种后端，一个面板

    Git 走版本库，WebDAV 连你自己的网盘。切换后端只是换一个提供者，拉取、推送、自动同步的操作方式完全一致。

  • ✓

    冲突看得见，不会静默覆盖

    Git 下哪一篇、哪几行、两边各改了什么，都摆在面板里；WebDAV 靠 ETag 比对，远端被动过就停下来问你。

  • ✓

    一键拉取与推送

    绑好就有按钮，也可以打开自动推送，改完即传。远程有新提交会主动察觉，推之前告诉你动了哪些文件。

##还能做什么

编辑器之外，Inkase 也是一套完整的文档工作台。

写作

排版自定义
正文字体、代码字体、行高都能调；编辑器内 Ctrl+滚轮 即时缩放字号。
三种主题
浅色、深色、跟随系统。
自动保存与恢复
编辑内容实时快照，异常退出后自动恢复现场。

管理

文件夹工作区
像资源管理器一样浏览、新建、重命名、拖拽移动。
多标签页
同时打开多篇文档，标签之间随意切换。
全文搜索
基于 ripgrep 跨文件查找内容；Ctrl+P 毫秒级快速打开。

互通

导入
DOCX、Markdown 文件，以及整个文件夹。
导出
Markdown 与 PDF，支持批量导出。
外部修改监听
文件在 Inkase 之外被改动时自动察觉，提示重载而不是默默覆盖。
